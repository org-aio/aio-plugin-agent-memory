# 随心记

`Notes` 编排来源列表、服务端搜索和分页；`composer` 使用稳定请求 ID 收件，按空间保留文本与图片草稿。`attachments` 负责浏览器端图片校验/压缩和按权限读取原图，`item` 展示净化 Markdown 与附件入口，`dialogs` 提供完整详情、显式打开原文编辑和确认删除。

编辑发出 `PUT /sources/{id}` 并携带预览版本；失败不关闭编辑器。原文只在提交者主动点击编辑后获取，不写浏览器持久缓存。来源权限由后端返回，服务端继续重新鉴权。

列表使用 `distinct=true`，去重后的总数与分页由服务端统一计算。重复提交显示“内容已存在，无需重复添加”，保留草稿供修改；重复编辑保留编辑器，不新增来源或整理任务。
