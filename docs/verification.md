# 验证记录

本地验证日期：2026-09-11。Kotlin Toolchain 0.12.0-dev-4233，Kotlin 2.4.10，Compose 1.12.0-beta03。

- 共享领域测试 4 项：校验、标题标签规整、显式双向链接、有界循环图遍历。
- 上游图谱布局测试 2 项：边吸引、极小视口和拖动固定性。
- Kotlin Component 经 Wasmtime 运行，连接真实 PostgreSQL：节点 CRUD、关系、来源导入、正文搜索、上下文引用、过期版本拒绝、失败写入不改变图谱、跨租户拒绝、数据库能力拒绝、实例替换持久化、删除级联均通过。
- Chrome / Playwright，桌面 1440×960、移动端 390×844：真实 Compose canvas，新增、编辑、确认/取消删除、刷新保留数据通过。
- 桌面实际选择 Markdown 文件导入，导出内容包含关系与节点引用；移动端编辑 Dialog 无横向溢出。
- 断网拖动与图谱/列表切换：0 个服务请求。截图像素变化超过 4000 像素，不是静态图片。
- 两种视口正常流程控制台错误为 0，无外部资源请求；沙箱阻止读取父窗口 DOM 和 Cookie，无票据请求返回 403。
- 字体文件临时失败后出现重试入口，恢复资源后界面成功加载。

浏览器报告和截图由 `npm run test:browser` 输出到忽略提交的 `test-results/`。
