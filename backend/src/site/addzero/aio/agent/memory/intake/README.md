# 收件与任务

事务内保存加密原文、净化来源、秘密引用和待整理任务。公共来源始终返回净化内容；原文及秘密有单独的授权读取路径。任务只向模型工作进程提供净化正文。

请求 ID 在空间和提交者范围内唯一，重试需对应相同原文。任务持有 180 秒租约，最多 5 次失败，暂停不消耗重试次数。提交重新校验工作身份、当前成员权限、原提交者权限、秘密引用归属及条目版本，所有知识和任务状态原子提交。

明确的整段秘密说明由 shared 规则识别，仅能修改本人在同一原对话中的保密暂存来源，原文保持加密且不可变。净化来源修订、补充说明来源及 wiki 所引用的来源版本分别留痕。无法确定用途时继续保密暂存。
